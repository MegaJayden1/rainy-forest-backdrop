# rain-watcher

A Claude Code mod that draws an animated backdrop behind the conversation in the Claude desktop and mobile apps: a misty pine forest in the rain.

- **Idle:** soft, steady rain.
- **While Claude works:** heavier, slanted rain and a thunderstorm, with lightning bolts striking every few seconds.

The terminal draws no backdrop. The mod switches the app to dark mode while it is on.

## Install

At the prompt of a terminal session:

```
/plugin install rain-watcher --marketplace MegaJayden1/rainy-forest-backdrop
```

Answer `y` to add the marketplace, then press Enter to pick the user scope.

From a shell:

```bash
claude plugin install rain-watcher --marketplace MegaJayden1/rainy-forest-backdrop
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `MegaJayden1/rainy-forest-backdrop`, then Add plugin.
